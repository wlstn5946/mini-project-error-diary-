# SCREEN-SPEC: 에러 해결 일기 (v3)

## 1. 문서 설명
- 화면 흐름, 예시 이미지, 화면 상태를 담는 문서다. 기능 설명은 PRD에 있으므로 여기서는 R-ID로만 가리킨다.
- **이번 버전(v3)의 범위는 "뼈대 + S-001 시리즈 선택·태그 입력"이다.** v2에 에러 해결 화면의 태그 입력 영역을 더한다.
- 참고 시안: `에러해결창_예시.png`, `내기록창_예시.png` (저장소 루트). 시리즈·태그 영역은 시안 ①을 참고하고, 나머지는 레이아웃만 참고한다.
- 시안 속 기능의 채택 여부는 Q-004에서 정하며, 이 문서에서 결정하지 않는다.
- 색상·간격 등 디자인 수치는 적지 않고 "시안 참고"로 대신한다.

모든 화면은 아래 구성을 같이 쓴다.

| 영역 | 이번 범위 | 이후 작성 |
|------|-----------|-----------|
| 왼쪽 사이드바 | 앱 이름 "🛠 에러 일기", 그 아래 메뉴 2개 (에러 해결 → 내 기록 순서, D-005) | 통계 영역 (시안 참고, Q-004 결정 후) |

**메뉴 강조 규칙**
- 현재 화면의 메뉴 하나만 강조한다.
- 나머지 메뉴는 기본 모양으로 둔다.
- 메뉴에 해당하지 않는 화면(S-004)에서는 어느 메뉴도 강조하지 않는다.
- 강조 모양은 시안을 참고한다.

#### 시리즈 선택 영역 (R-001, D-006, D-011)
- 시안 ①의 "시리즈 (선택)" 부분. 담당 팀원 1 (`frontend/src/features/records/SeriesSelect.tsx`)
- 목록은 A-004 `GET /api/series`로 가져온다 (최근 만든 순).
- 에러 해결 화면(`frontend/src/pages/SolvePage.tsx`)의 "에러 입력" 탭에 배치됨. 위치는 시안 ①처럼 "에러 메시지" 위.
- "AI 분석" 탭으로 갔다 와도 고른 시리즈와 입력 중인 새 이름이 그대로 남는다.

| 구성 | 내용 |

| "취소" 버튼 | 입력칸을 닫고 드롭다운으로 돌아간다. 드롭다운에서 고른 값은 그대로 남는다 |

**화면 상태**

| 상태 | 드롭다운 / 입력칸 | "+ 새 시리즈" | 안내 |
|------|-------------------|---------------|------|
| 목록 불러오는 중 | 드롭다운 비활성, "불러오는 중…" 표시 | 비활성 (중복 확인을 할 수 없어서) | "기존 시리즈를 고르거나 바로 새로 만들 수 있어요." |
| 목록 준비됨 (0개 포함) | 드롭다운 사용 가능. 0개면 "선택 안 함"만 있음 | 사용 가능 | 위와 같음 |
| 목록 불러오기 실패 | 드롭다운 비활성, "선택 안 함" | 사용 가능 | "시리즈 목록을 불러오지 못했어요. 시리즈 없이 계속하거나 새로 만들 수 있어요." + "다시 시도" 버튼 |
| 새 이름 입력 중 | 입력칸 | "취소"로 바뀜 | "새 시리즈는 에러를 저장할 때 함께 만들어져요." |
| 새 이름이 기존 이름과 중복 | 입력칸 | "취소" | "이미 있는 시리즈예요. "취소"를 누르고 목록에서 골라 주세요." (오류 색) |
| 목록 실패 상태에서 새 이름 입력 | 입력칸 | "취소" | "목록을 불러오지 못해 이름이 겹치는지 확인하지 못했어요." |

- 중복 비교: 앞뒤 공백을 빼고 대소문자를 구분하지 않는다. (D-017)
- 새 시리즈 이름은 이 영역에서 저장하지 않는다. 에러를 저장할 때 함께 만든다. (D-011)
- 새 이름이 비었거나 중복이면 "아직 쓸 수 없는 상태"로 화면에 알린다. 에러 저장 버튼을 막는 동작은 에러 등록(R-001, Q-001)과 함께 정한다.
- API 실패·로딩 중에도 다른 입력(에러 메시지 등)은 그대로 쓸 수 있다.

#### 태그 입력 영역 (R-001, D-006, D-018 ~ D-022)
- 시안 ①의 "태그 (최대 5개)" 부분. 담당 팀원 1 (`frontend/src/features/records/TagInput.tsx`)
- 자동 완성 목록은 A-004 `GET /api/tags` 전체를 받아 화면에서 거른다. (D-021)
- 위치: 시리즈 선택 영역 아래, "에러 메시지" 위. "AI 분석" 탭으로 갔다 와도 입력한 태그가 그대로 남는다.
- 추천 태그("+패키지" 등)는 만들지 않는다. (D-023, Later 후보)

| 구성 | 내용 |
|------|------|
| 라벨 | "태그 (최대 5개)" |
| 칩 | 추가한 태그를 입력칸 안 왼쪽에 칩으로 보여준다. 칩의 "×"로 하나씩 지운다 |
| 입력칸 | 칩 오른쪽. 안내 문구 "태그 입력 · 기존 태그 자동 완성" |
| 자동 완성 목록 | 입력값을 포함하는 기존 태그(대소문자 무시, 이미 추가한 태그 제외)를 입력칸 아래에 보여준다 |

**입력 규칙**
- Enter로 추가한다. 한글 조합 중(`isComposing`)의 Enter는 무시한다. 두 번 들어가거나 글자가 떨어지지 않게 하기 위해서다.
- 입력칸이 비어 있을 때 Backspace를 누르면 마지막 칩을 지운다.
- 이름은 앞뒤 공백 → 앞의 `#` → 다시 앞뒤 공백 순서로 지운다. 결과가 비면 추가하지 않는다. (D-019)
- 이미 추가한 태그와 대소문자만 달라도 같은 태그로 보고 추가하지 않는다. (D-019)
- 기존 태그와 대소문자만 다르면 기존 표기로 바꿔 추가한다. 예: `python` → `Python` (D-019)
- 5개가 찬 상태에서 더 추가하려 하면 추가하지 않고 안내한다. (D-022)
- 자동 완성 목록은 클릭하거나 ↑↓로 고른 뒤 Enter로 추가한다.
- 새 태그는 이 영역에서 저장하지 않는다. 에러를 저장할 때 함께 만든다. (D-020)

**화면 상태**
