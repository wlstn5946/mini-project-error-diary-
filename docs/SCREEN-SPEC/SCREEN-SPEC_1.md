# SCREEN-SPEC: 에러 해결 일기 (v1)

## 1. 문서 설명
- 화면 흐름, 예시 이미지, 화면 상태를 담는 문서다. 기능 설명은 PRD에 있으므로 여기서는 R-ID로만 가리킨다.
- **이번 버전(v1)의 범위는 "뼈대"다.** 메뉴로 두 화면(에러 해결, 내 기록)을 오가고, 각 화면에 제목만 있는 빈 화면이 뜨는 것까지만 다룬다.
- 참고 시안: `에러해결창_예시.png`, `내기록창_예시.png` (저장소 루트). 이번 버전에서는 레이아웃만 참고한다.
- 시안 속 기능의 채택 여부는 Q-004에서 정하며, 이 문서에서 결정하지 않는다.
- 색상·간격 등 디자인 수치는 적지 않고 "시안 참고"로 대신한다.

## 3. 공통 레이아웃
모든 화면은 아래 구성을 같이 쓴다.

| 영역 | 이번 범위 | 이후 작성 |
|------|-----------|-----------|
| 왼쪽 사이드바 | 앱 이름 "🛠 에러 일기", 그 아래 메뉴 2개 (에러 해결 → 내 기록 순서, D-005) | 통계 영역 (시안 참고, Q-004 결정 후) |
| 오른쪽 본문 | 현재 화면의 제목 | 화면별 내용 (4절) |

**메뉴 강조 규칙**
- 현재 화면의 메뉴 하나만 강조한다.
- 나머지 메뉴는 기본 모양으로 둔다.
- 메뉴에 해당하지 않는 화면(S-004)에서는 어느 메뉴도 강조하지 않는다.
- 강조 모양은 시안을 참고한다.

## 5. 화면 이동 규칙

| 상황 | 동작 |
|------|------|
| 메뉴 클릭 | 해당 화면 경로로 이동하고, 메뉴 강조를 그 화면으로 바꾼다 |
| 현재 화면의 메뉴 다시 클릭 | 화면을 그대로 둔다 |
| 처음 접속 (`/`) | S-001 에러 해결(`/solve`)로 이동한다 |
| 없는 경로 접근 | S-004 "찾을 수 없음" 안내를 보여준다. 사용자는 사이드바 메뉴로 다른 화면에 갈 수 있다 |
