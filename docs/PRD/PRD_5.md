# PRD: 에러 해결 일기

> 이 문서는 "큰 틀"만 담는다. 세부 기능은 개발하면서 채운다.
> 결정의 이유는 DECISIONS_N에 적고, 여기서는 D-ID만 참조한다.

## 1. 제품 개요
- **한 줄 설명**: 에러 메시지를 입력하면 내가 이전에 해결한 기록을 먼저 찾아 보여주고, 기록이 없으면 AI(Gemini)가 해결 방법을 제안하는 에러 해결 기록 앱
- **해결하려는 문제**: 이전에 해결한 에러의 기록이 남지 않아, 같은 에러를 다시 만나면 처음부터 다시 찾아야 한다
- **사용자**: 1인 사용, 로그인 없음 (D-002)
- 세부 사용자 상황은 [결정 필요]

## 2. 목표와 성공 기준
- 같은 에러를 다시 입력하면 이전 해결 기록을 먼저 보여준다
- 기록이 없을 때 AI 제안을 받아 시도 → 해결까지 기록할 수 있다
- 해결된 에러마다 "내 한 줄 정리"가 남는다
- 정량 지표는 [결정 필요] (Q-006)

## 3. 핵심 흐름
에러 입력 → 기존 기록 확인 → 없으면 AI 제안 → 시도 기록 → 해결 → 내 한 줄 정리

(화면 상세는 SCREEN-SPEC_N.md에서 다룬다)

## 4. 범위
- **만들 것 (Now)**: R-001 ~ R-005
- **나중에 (Later)**: 복습 퀴즈 (D-004), 추천 태그 (D-023, 후보), 시도 출처 표시 (D-032, 후보)
- **안 만들 것**: 로그인 (D-002), 학습 기록 기능 (D-003)

## 6. 규칙
- **확정**
  - 시리즈와 태그는 에러를 입력할 때 지정한다 (D-006)
  - 새 시리즈는 따로 만들지 않고 에러를 저장할 때 함께 만든다 (D-011)
  - 새 태그도 따로 만들지 않고 에러를 저장할 때 함께 만든다 (D-020)
  - 태그는 에러 하나당 최대 5개 (D-022)
  - 에러는 새 에러로 확정되는 순간(AI에게 묻기 직전) 미해결로 저장한다 (D-025)
  - "해결됨"으로 기록하면 내 한 줄 정리가 필수이고, 시도 저장과 해결 처리가 함께 이뤄진다 (D-026)
  - "해결 안 됨"·"일부 해결"이면 실패 시도를 저장하고 AI에게 다음 방법을 다시 묻는다. 에러는 미해결로 남는다 (D-027, D-029)
  - 해결된 에러에는 시도를 더 추가하지 않는다 (D-032)

## 7. MVP 완료 조건
- 입력 → 검색 → AI 제안 → 시도 → 해결이 끊김 없이 동작한다

## 8. 제약 사항
- **기술 스택**: FastAPI + React(Vite, TypeScript) + SQLite + Gemini API
- **로그인 없음**: 1인 사용 (D-002)

## 9. 열린 질문
- Q-001: 에러 등록 시 입력 항목은 무엇인가? — 결정 (2026-11-02)
  - 에러 메시지(필수), 상황(선택), 시리즈(선택), 태그(최대 5개). 저장 필드는 D-024, 저장 시점은 D-025
  - 남은 것: 입력 길이 제한 (Later)
- Q-002: 기존 기록 검색은 어떤 기준으로 일치를 판단하는가? [결정 필요]
- Q-003: AI 제안은 언제 호출하고, 결과를 저장하는가? — 일부 결정 (2026-11-02)
  - 호출: 새 에러로 확정되는 순간(D-025), 그리고 "해결 안 됨 → 다음 방법 제안받기"에서 이전 시도를 붙여 다시 호출(D-027)
  - 저장: AI 제안 내용은 저장하지 않는다 (D-027)
  - 남은 것: 시안 ③의 "AI 피드백"(한 줄 정리에 대한 피드백)을 넣을지 [결정 필요]
- Q-004: 참고 시안(에러해결창_예시.png, 내기록창_예시.png)의 기능 중 무엇을 요구사항으로 채택하는가? — 일부 결정
  - 채택 (2026-11-02): 에러 해결 화면의 시리즈 선택(드롭다운, "+ 새 시리즈") (R-001, 화면은 SCREEN-SPEC S-001)
  - 채택 (2026-11-02): 에러 해결 화면의 태그 입력(칩, 자동 완성, 최대 5개) (R-001, 화면은 SCREEN-SPEC S-001)
  - 채택 (2026-11-02): 에러 해결 화면의 시도 기록(시안 ②: 무엇을 했나요, 결과 3가지, 내 한 줄 정리)과 해결 완료 안내(시안 ③), 상황 입력(시안 ①) (R-001, R-004, D-024 ~ D-029)
  - 채택 (2026-11-02): 내 기록 화면의 날짜별 목록, 상태 필터(전체/미해결만/해결만), 태그 필터(여러 개는 모두 포함), 에러 메시지 검색, 에러 일기 상세(시도 목록, 한 줄 정리) (R-005, D-035)
  - Later 후보: 추천 태그("+패키지 +Gemini +import") (D-023), 시도 출처 표시 (D-032)
  - 이후 단계 (내 기록): 시리즈별 보기(시리즈 안 순서 Q-005), "재사용 N" 배지와 사이드바 "재사용 해결"(A-003 이후), 필터 칩 개수와 사이드바 통계, 태그 관리·시리즈 수정·상세에서 태그·시리즈 수정, 상세의 "시도 추가"·"한 줄 정리 수정"(A-007), "1주차·2주차" 묶음, 해결 완료 영역의 "에러 일기 보기" 연결
  - [결정 필요]: 시안 ③④의 "AI 피드백" (Q-003)
  - 나머지 기능: [결정 필요]
