# PRD: 에러 해결 일기

> 이 문서는 "큰 틀"만 담는다. 세부 기능은 개발하면서 채운다.
> 결정의 이유는 DECISIONS_N에 적고, 여기서는 D-ID만 참조한다.

## 1. 제품 개요
- **한 줄 설명**: 에러 메시지를 입력하면 내가 이전에 해결한 기록을 먼저 찾아 보여주고, 기록이 없으면 AI(Claude)가 해결 방법을 제안하는 에러 해결 기록 앱
- **해결하려는 문제**: 이전에 해결한 에러의 기록이 남지 않아, 같은 에러를 다시 만나면 처음부터 다시 찾아야 한다
- **사용자**: 회원가입으로 여러 계정을 만들어 쓰고, 계정마다 자기 기록만 본다 (D-082, D-002는 변경됨)
- 세부 사용자 상황은 [결정 필요]

## 2. 목표와 성공 기준
- 같은 에러를 다시 입력하면 이전 해결 기록을 먼저 보여준다
- 기록이 없을 때 AI 제안을 받아 시도 → 해결까지 기록할 수 있다
- 해결된 에러마다 "내 한 줄 정리"가 남는다
- 정량 지표 (Q-006 결정, D-129): 해결률, 재사용 해결 비율, 써 보기 성공률, 오래된 미해결 수. 내 기록 "통계" 탭에서 본다. 목표 숫자는 한 달 써 본 뒤 정한다
- 지표의 경계 (D-003): "다음에 에러를 만났을 때 도움이 되는 정보"만 센다. 연속 기록일·레벨·배지·목표 달성률·날짜별 추이는 학습 기록이라 넣지 않는다

## 3. 핵심 흐름
에러 입력 → 기존 기록 확인 → 없으면 AI 제안 → 시도 기록 → 해결 → 내 한 줄 정리

(화면 상세는 SCREEN-SPEC_N.md에서 다룬다)

## 4. 범위

## 6. 규칙
- **확정**
  - 시리즈와 태그는 에러를 입력할 때 지정한다 (D-006)
  - 새 시리즈는 에러를 저장할 때 함께 만들거나, 내 기록 "시리즈별" 탭에서 따로 만든다 (D-011, D-061)
  - 새 태그도 따로 만들지 않고 에러를 저장할 때 함께 만든다 (D-020)
  - 태그는 에러 하나당 최대 5개 (D-022)
  - 에러와 시도는 화면에만 모아 두고, "기록 저장"을 누를 때 한 번에 저장한다. 마지막 시도가 해결됨이면 해결, 아니면 미해결이다 (D-065, D-066)
  - "해결됨"으로 기록하면 내 한 줄 정리가 필수이고(그 밖에는 선택, D-067), 시도 저장과 해결 처리가 함께 이뤄진다 (D-026, D-065)
  - "해결 안 됨 → 다음 방법 제안받기"는 그 시도를 화면에 모아 두고 AI에게 다음 방법을 다시 묻는다. 저장은 "기록 저장" 때 한다. 마지막 시도가 해결 안 됨·일부 해결이면 에러는 미해결로 남는다 (D-027, D-029, D-065)
  - 해결된 에러에는 시도를 더 추가하지 않는다 (D-032)
  - 미해결 기록은 상세의 "이어서 해결하기"로 에러 해결 화면에 다시 들어와 같은 기록에 시도를 이어서 붙인다. 새 기록을 만들지 않고, 에러 메시지·상황·태그·시리즈는 고치지 않는다. 기존 실패 시도는 AI에게 다시 묻을 때 함께 보낸다 (D-075 ~ D-077)
  - 비슷한 기록은 해결된 기록 중 유사도 60% 이상만, 유사도 높은 순으로 보여준다. 위 2건은 칸에 보이고 나머지는 스크롤로 본다 (D-040, 유사도는 전체·핵심 줄 중 높은 값, D-118)
  - 비슷한 기록의 "이 방법 써 보기"는 저장 없이 원본 해결법을 시도 1로 채운 시도 기록 화면으로 가고, 결과는 사용자가 고른다 (D-128. 이전에는 바로 해결됨으로 저장, D-069)
  - "이 방법 써 보기"로 시작해 그 방법으로 해결된 재사용 기록은 맨 처음 원본을 가리킨다(원본은 해결된 기록이어야 한다). 적용한 방법으로 해결됐을 때만 원본을 가리키고, 해결 안 됨이거나 AI 방법으로 해결하면 가리키지 않는다 (D-128). 내 기록의 날짜별·태그별 탭에서는 원본 아래로 접어 "재사용 N"으로 보여주고, 시리즈별 탭은 묶지 않는다. 재사용 기록은 태그·시리즈를 따로 가지며 원본을 고쳐도 바뀌지 않는다. 원본을 지워도 재사용 기록은 남고, 그중 가장 오래된 것이 새 원본이 되어 나머지가 그것을 가리킨다. 에러 해결 화면의 비슷한 기록도 원본 기준으로 묶어 카드 1장에 "재사용 N회"로 보여준다 (D-080, D-081, D-121)
  - 기록 삭제는 확인 후 완전 삭제이고, 그 기록의 시도·태그 연결도 함께 지워진다. 쓰이지 않게 된 태그·시리즈는 남는다 (D-043, D-044, D-046)
  - 기록 수정은 상황·시리즈·태그만 가능하고 에러 메시지는 바꾸지 않는다 (D-047, D-048)
  - 태그·시리즈 이름을 바꿀 때 같은 이름이 있으면 막고, 쓰이는 태그·시리즈도 지울 수 있다(기록은 남는다) (D-049, D-050)
  - 시리즈 안 순서는 시리즈에 넣은 순서가 기본이고 바꿀 수 있다. 시리즈가 없는 기록은 시리즈별 보기에 나오지 않는다 (D-051, D-053)
  - 미해결이고 등록한 지 14일 이상 지난 기록은 "오래된 기록"이다(해결된 기록은 해당 없음). 내 기록의 "오래된 기록" 버튼, 사이드바 미해결 칸, 목록 항목에 깜빡이는 작은 빨간 불로 알리고, 지우는 것은 기존 기록 삭제를 그대로 쓴다 (D-078)
  - 에러 일기 상세에서 기록을 Markdown 파일로 내려받거나 브라우저 인쇄로 PDF로 저장할 수 있다. 화면이 이미 불러온 저장된 내용만 내보내고(편집 중인 값은 아님), 미해결 기록도 가능하다. 새 API·패키지는 없다 (D-079)
